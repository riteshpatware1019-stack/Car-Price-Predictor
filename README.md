# 🚗 Car Price Predictor

A Machine Learning project that predicts the **estimated price of a car** based on different car features. This project demonstrates the basic workflow of a real-world Machine Learning regression problem.

## 📌 Project Overview

The **Car Price Predictor** analyzes historical car data and uses Machine Learning to predict the price of a car.

The project includes data preprocessing, exploratory data analysis, feature preparation, model training, and price prediction.

## 🎯 Objectives

* Analyze and clean car dataset
* Perform Exploratory Data Analysis (EDA)
* Identify important factors affecting car prices
* Train a Machine Learning regression model
* Evaluate the model performance
* Predict prices for new car details

## 🛠️ Technologies Used

* **Python**
* **Pandas**
* **NumPy**

## 📊 EDA

The dataset is analyzed using Pandas and Matplotlib to understand:

* Car price distribution
* Relationship between car features and price
* Important factors affecting price
* Numerical feature relationships

## 🤖 Machine Learning

This project uses a **regression approach** because car price is a continuous numerical value.

The dataset is divided into training and testing data. The trained model is then used to predict prices for unseen car data.
